ADR-010 (2026-10-15) Permission model: inbox (what the employee sees) and line (what the employee replies from) are separate tables (inbox_access, line_access). inboxes.visibility_mode = all | assigned_only. A line feeds exactly one inbox. line_access levels: 10 view, 20 reply (+ may REQUEST send-as), 30 send-as without approval (also needs permission inbox.send_as), 40 manage.
ADR-011 (2026-10-15) Reply defaults to the line the conversation arrived on. Replying from another line needs an authorization request (supervisor 5 min → manager 10 min → late approval accepted until 120 min; grant valid 60 min; max 5 open requests per employee; reject cooldown 15 min; all durations are settings and a snapshot is stored per request). Approval opens a NEW conversation from the other line, assigned to the requester and linked to the original. One grant cancels the employee's other open requests on that conversation.
ADR-012 (2026-10-15) Enforcement is always in hub-api; the UI only hides. Chatwoot hides inboxes the agent is not a member of, so Hub adds its own visibility layer plus per-conversation exceptions (conversation_access_grants). Open risk: inside an iframe Chatwoot cannot enforce "assigned only" or per-conversation exceptions — verify in HUB-005/HUB-012 before promising it.
ADR-013 (2026-10-15) Groups: a group counts only if the main line is a member and admin. Membership state per (group, line) = member | not_member | unknown with a source (manual > hub_action > wa_event > message_seen > single_fetch). No bulk participant fetch (rate-overlimit). Group templates define required lines/kinds; reports compare to the template only. Not every line must be in every group. "Add number to group" requests go straight to the manager (assumption, to confirm).
ADR-014 (2026-10-15) Settings precedence: global default → department/role → staff; deny wins for permissions/allow-lists; role beats department when both set the same key (assumption, to confirm). Idle threshold default 300 s, per-user override. Every change is audited.
ADR-015 (2026-10-15) Attendance: login/logout + active-time counter driven by heartbeat (30 s) + Page Visibility + idle detection; session closed at last heartbeat if the browser is closed without logout. Response time measured inside each employee's working hours. Mobile-first + light/dark toggle from day one.
