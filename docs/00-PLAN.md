# خطة TripYou_ChatHUB — النسخة المباشرة v3 (بدون Chatwoot)

## 1. الرؤية المحدثة
منصة واتساب مركزية موحدة لفريق TripYou (5–15 موظفاً): إدارة محادثات واتساب لعدة أرقام وخطوط متصلة **مباشرة بـ Evolution API**، جهات اتصال موحدة، مهام، اجتماعات، تقارير، وصلاحيات دقيقة. تم الاستغناء نهائياً عن Chatwoot لتحرير موارد السيرفر (توفير 60% من الرام) والتخلص من قيود الـ Iframe والتعقيدات غير الضرورية.

## 2. القرارات المعتمدة
- **بدون Chatwoot نهائياً:** اتصال مباشر بين Hub و Evolution API عبر Webhooks و REST API.
- **واجهة محادثات أصلية (Native Chat Inbox):** مبنية بـ Next.js 14 + Tailwind + TypeScript بتصميم عربي أصيل (RTL)، تدعم التوقيع الذكي التلقائي واختيار خط الإرسال لكل رسالة.
- **نطاقات فرعية مجانية عبر sslip.io:** hub.69.62.122.89.sslip.io و evo.69.62.122.89.sslip.io (توجيه مباشر لـ IP السيرفر 69.62.122.89 بدون الحاجة لإدارة DNS على resvbar.com).
- **قاعدة البيانات:** PostgreSQL schema `hub` تحتوي على جداول المحادثات `hub.conversations`، والرسائل `hub.messages`، والخطوط `hub.lines`، والصلاحيات `hub.permissions`، وجهات الاتصال `hub.contacts`.
- **استهلاك السيرفر:** بعد إيقاف شات ووت، خادم Hostinger VPS (8GB) سيكون مريحاً جداً لتشغيل 10+ خطوط واتساب على Evolution API مع Hub و n8n بدون أي ضغط.

## 3. البنية المعمارية
`hub-web` (Next.js 14 + RTL + Tailwind + shadcn) ⇄ `hub-api` (Evolution Webhooks + REST API) ⇄ PostgreSQL / Supabase ⇄ `Evolution API` (Baileys).

## 4. الميزات الحصرية في النظام المباشر
1. **التبديل الفوري لخط الإرسال داخل نفس المحادثة أو المجموعة:** الموظف يختار الرقم الذي يريد الإرسال منه بضغطة زر.
2. **التوقيع الذكي الآلي:** إضافة اسم الموظف ورقم الخط وقسمه تلقائياً للرسائل الصادرة مع إمكانية التفعيل والتعطيل بنقرة زر.
3. **دليل جهات اتصال موحد (Contacts Master):** استيراد CSV وتطبيع E.164 ومزامنة الأسماء.
4. **أمان عالي وصلاحيات دقيقة (RBAC):** تحديد من يحق له الرد، أو الإرسال باسم رقم معين، أو مجرد القراءة.
