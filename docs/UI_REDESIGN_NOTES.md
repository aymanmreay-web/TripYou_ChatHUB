# ملاحظات إعادة تصميم الواجهة (Claude) — للوكيل الأساسي: راجع وتحقق ثم ادمج

الفرع: `claude/ui-foundation` — مبني على `origin/main` عند الالتزام `8ab8aee`.
المعاينة التفاعلية للتصميم الكامل (ملف واحد يعمل بالمتصفح): `docs/design-preview/hub-v2.html`.

## 1) الهدف
تصميم موحّد واحترافي: زجاج + ألوان جوجل المتحركة كافتراضي، وضع داكن وفاتح مريحان، مركز مظهر موسّع للمدير وتخصيص أقل للموظف، تجاوب كامل (جوال/تابلت/حاسوب)، ثم تطبيق أندرويد لاحقاً من نفس الكود (PWA أولاً ثم Capacitor).

## 2) ما يحتويه هذا الفرع (الدفعة 1: الأساس، بدون كسر أي شيء)

## 3) نقاط تحتاج انتباه المراجع
1. **الثيم الافتراضي لم يتغير** (`DEFAULT_THEME = 'theme-purple'` في AppContext.tsx). السبب: لم أستطع فحص التطبيق الحقيقي بصرياً (يحتاج Supabase وتسجيل دخول). بعد مراجعتك لـ `/design-kit` والصفحات بثيم جوجل، غيّر القيمة إلى `'theme-google'` وسطر الـ FOUC في layout يقرأها من التخزين.
2. **أصناف purple-\* تغيّرت دلالتها**: كانت ثابتة بنفسجية حتى في الثيم الأزرق، والآن تتبع الثيم. في الثيم البنفسجي الفروق صغيرة: `purple-950` كان `#3B0764` وصار `#2E0B55` (وفي الفاتح `purple-600` صار `#7C3AED`). افحص بصرياً أن لا شيء تدهور.
3. **تحميل الخطوط**: ملفات CSS لكل الخطوط تدخل الحزمة، لكن ملفات الخط نفسها لا تُنزَّل إلا عند الاستخدام. إن أردت تقليل حجم CSS لاحقاً يمكن تحميل خط المستخدم المختار فقط.
4. **اسم Avatar مكرر**: يوجد `Avatar` في `@tripyou/ui` وآخر جديد في `components/ui`. أبقيتهما منفصلين عمداً لعدم كسر الاستخدامات الحالية. الخطوة التالية توحيدهما.
5. **الأمان/النشر**: لم أنشر على السيرفر ولم ألمس أسرار أو قاعدة بيانات. النشر يبقى عبر مسار GitHub Actions المعتمد بعد دمجك.

## 4) كيف تتحقق
```
npm ci
npm run build -w apps/hub-web      # نجح عندي (Next 14.2، كل الصفحات)
npx tsc --noEmit -p apps/hub-web   # بدون أخطاء
```
ثم في المتصفح: سجّل دخولاً، افتح `/design-kit`، بدّل الثيم (الزر الجديد بحلقة الألوان) والوضع الداكن/الفاتح، وجرّب كل الصفحات للتأكد من الألوان.

## 5) الخطوات القادمة المقترحة (دفعات صغيرة، كل واحدة قابلة للمراجعة)
```
الدفعة 2  قاعدة بيانات المظهر: جدول appearance_settings بثلاث طبقات (افتراضي عام / حسب الدور / حسب المستخدم) + RLS،
          وتطبيقها كمتغيرات CSS عند الإقلاع (نفس المتغيرات تخدم تطبيق أندرويد).
الدفعة 3  صفحة «المظهر والتخصيص» للمدير (ثيمات، لون رئيسي، خطوط، استدارة، شدة الزجاج، الحركة، شكل الفقاعات، صلاحيات الموظف)
          + نسخة مخفّفة في «ملفي» للموظف. المرجع: التبويبات في docs/design-preview/hub-v2.html.
الدفعة 4  توحيد التنقل: الشريط السفلي للجوال، أوراق جانبية (Sheet) للإضافة والتعديل، نوافذ تأكيد، صفوف قوائم موحدة، منتقي ملفات وألوان موحد.
الدفعة 5  تقسيم NativeChatInbox.tsx (أكثر من 3000 سطر) إلى مكونات، وتطبيق الأفاتار الجديد وكبسولة الاسم في رأس المحادثة.
الدفعة 6  PWA كامل (manifest وservice worker) ثم تغليف Capacitor لأندرويد.
```
ميزات الموظف المقترحة (تحفيزية): حلقة هدف اليوم، متوسط أول رد، أيام الالتزام بمهلة الرد، رسم أسبوعي، حالة التواجد، كتم التنبيهات ليلاً.

## 6) قواعد التجاوب (للالتزام بها في كل صفحة)
```
جوال     أقل من 640px        شريط تبويب سفلي، أوراق سفلية، لوحة واحدة مع تنقل دفعي
تابلت    640 إلى 1023px      قائمة أيقونات + لوحتان
حاسوب    1024px وأكثر        قائمة كاملة + ثلاث لوحات
```
هدف لمس لا يقل عن 44px، مناطق آمنة (safe-area)، استخدام dvh، لا اعتماد على hover، واحترام prefers-reduced-motion.

## 7) الخطوط وحقوقها
الخطوط المستضافة كلها مفتوحة الترخيص (SIL OFL). خطوط قنوات beIN وMBC والجزيرة مملوكة تجارياً ولا تُضمَّن دون ترخيص. يمكن للمالك رفع ملف خط مرخّص لاحقاً (الخانة موجودة في التصميم) وتُحفظ على السيرفر.

## 8) قواعد المشروع التي التزمت بها
RTL: `dir="rtl"` و`text-right` في المكونات الجديدة، و`bdi`/`isolate-latin` للنصوص اللاتينية داخل العربية، واستخدام `gap`/خصائص منطقية (`ms/me/ps/pe/start/end`) بدل `ml/mr`.

## الدفعة 2 (الفرع `claude/ui-shell`): تطبيق الثيم على الشاشات الحالية
السبب: بعد دمج الدفعة 1 ظهر أن اختيار ثيم جوجل يغيّر الألوان فقط، بينما الصفحات كُتبت للثيم الداكن (نصوص `text-white`، وخلفيات `slate/purple` غامقة)، فتظهر الشاشة الفاتحة بتباين سيئ.
```
globals.css      طبقة theme-google: خلفية aurora متحركة، زجاج للشريط الجانبي والهيدر، شريط ألوان جوجل أعلى الهيدر،
                 وتصحيح الوضع الفاتح لأصناف slate/purple/white المكتوبة للداكن (محددات [class*=...] محصورة بـ html.theme-google)
layout.tsx       عنصر .aurora (مخفي إلا في ثيم جوجل)
109 سطر tsx     text-white على عناصر بلا خلفية ملونة صار text-[var(--text-main)] (في البنفسجي الداكن لا فرق مرئي)
NativeChatInbox  أفاتار المحادثات بالحرفين الأولين (تجاهل «ال») بدل الحرف الواحد، وبألوان الثيم
```
**تحذير للمراجع:** هذه الدفعة مبنية على لقطة شاشة من المالك وعلى الكود فقط، ولم أستطع فتح التطبيق الحقيقي. الحل بالمحددات `[class*=...]` مؤقت وسريع، والحل الدائم هو نقل هذه الأصناف إلى متغيرات الثيم داخل المكونات (ضمن الدفعتين 4 و5). افحص بصرياً الصندوق والمفضلة والإدارة في الفاتح والداكن.

## الدفعة 2.1 (الفرع `claude/ui-fixes`): إصلاحات من لقطات المالك بعد النشر
المشاكل التي ظهرت: (1) صفوف قائمة المحادثات وجدول الموظفين كلها بخلفية زرقاء لأن المحدد `[class*="bg-purple-9"]` كان يلتقط أيضاً `hover:bg-purple-950/20`. (2) نصوص الشارات الملونة (`text-emerald-300` وأخواتها) باهتة على الخلفية الفاتحة. (3) القوائم المنسدلة الأصلية (select) بألوان نظام التشغيل في الداكن. (4) حقول التوقيع بنص باهت (`text-purple-100`).
```
الإصلاح                                       التفصيل
محددات بداية الصنف فقط                         [class^="x"], [class*=" x"] بدل [class*="x"]، فلا تلتقط variants
ألوان النص في الفاتح                           درجات 100-400 لـ emerald/green/amber/yellow/red/rose/blue/sky/cyan/teal/indigo/pink/orange/fuchsia تُغمَّق إلى 700
select/option                                 color-scheme + خلفية ونص من متغيرات الثيم
```
