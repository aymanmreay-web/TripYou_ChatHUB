# TripYou_ChatHUB — حالة العمل والمتبقي

آخر تحديث: 2026-11-06 — الفرع: `wip/antigravity-continue`

## ما تم إنجازه
- صناديق الوارد (`inboxes`)، هوية الشركة (`company_settings` + شعار في Storage)، الوسوم والحالات: مربوطة بقاعدة Supabase مع إظهار الأخطاء.
- المصادقة الحقيقية: `lib/authDb.ts` — جلسة Supabase ← صف `hub.staff` ← الدور والصلاحيات من `hub.roles` / `hub.role_permissions`.
  - الحالات: `anonymous` → `/login`، `pending`/`blocked` → `/pending-approval`، `active` → التطبيق.
  - حُذف مبدّل الأدوار التجريبي من الهيدر، وحُذف الدخول الافتراضي `super_admin`.
- صفحة الدخول: بلا بيانات مسبقة، زر واحد "تسجيل دخول" + Google، شعار/اسم الشركة من الإعدادات.
- قاعدة البيانات: زُرعت الصلاحيات (`hub.permissions`) وربطت بالأدوار (`super_admin`, `sales_lead`, `support_agent`, `observer`, `trainee`).
- صفحة الموظفين: تحميل وحفظ فعلي للدور والحالة والخطوط والصناديق وقفل المحادثات، مع عرض الأخطاء. أُزيل حقل "القسم الداخلي".
- بناء `npx tsc --noEmit` و `npm run build` ناجحان.

## ما تبقى (بالترتيب المقترح)
1. **سياسات RLS الحقيقية**: حالياً سياسة "السماح للجميع" (للمصادَقين). المطلوب: سياسات حسب الدور (`staff.manage` للتعديل فقط).
   - ملاحظة: هذا خارج نطاق التعليمات الحالية؛ يُنفَّذ لاحقاً عند ضبط الأمان.
2. **تفعيل Google OAuth** في لوحة Supabase (Client ID/Secret) وتجربة التدفق كاملاً.
3. **حساب تجريبي** للاختبار ثم حذفه بعد التحقق.
4. **حماية المسارات بالصلاحية**: الوحدات مفلترة بالصلاحيات في الواجهة فقط (`filterModulesForUser`)؛ المطلوب فحص `required_permission` على كل صفحة.
5. **إزالة النصوص**: "Evolution API" في `Header.tsx`, `signature/page.tsx`, `admin_dashboard/page.tsx`, `ComingSoonView.tsx`؛ و"3D Contacts Hub" في صفحة جهات الاتصال.
6. **المفضلة**: فتحها داخل نفس الصفحة كبقية الأقسام (حالياً `Sidebar` يوجّه إلى `/inbox?filter=favorites`).
7. **قواعد الوسوم التلقائية**: واجهة لجدول `hub.tag_rules` (تبويب جديد في صفحة الوسوم).
8. **الدردشة (`NativeChatInbox.tsx`)**:
   - تجميع 4 صور كألبوم عند الإرسال (تعليق واحد مرتبط بالألبوم).
   - عارض ألبوم بالتنقل التالي/السابق داخل عرض المحادثة دون إغلاق.
   - حذف عبارة "عرض الصورة بالدقة الكاملة"، وتغيير زر التحميل إلى "حفظ الى الجهاز المحلي".
   - مشاركة: اختيار رقم الإرسال أولاً ثم المستلم، وإعداد "خط المشاركة الافتراضي" لكل مستخدم، وإعادة تصميم نافذة المشاركة/التثبيت وتكبيرها.
   - PDF + Excel معاً: معاملتهما كمستندات (بلا خيارات الصورة/HD).
9. **نظام الألوان الموحد** (منتقي ألوان) وإنشاء حالات مخصصة (مواسم/مناسبات/عقود).
10. **صفحة الخطوط**: حذف "عبر محرك Evolution API" وتقليل النصوص الشارحة في كل الصفحات.
11. **Webhook → قاعدة البيانات** وفحوص الإرسال من جهة الخادم (line_access، القفل، التوقيع).
12. **مزامنة المستودع**: تحديث `db/supabase_master_setup.sql` لمطابقة مخطط `hub` الحي، وإضافة ترحيلات الجداول الجديدة.
13. **النشر**: `cd /opt/tripyou-chathub && git pull && docker-compose -f docker-compose.hub.yml build --no-cache && up -d`، وإيقاف Chatwoot (HUB-009).
